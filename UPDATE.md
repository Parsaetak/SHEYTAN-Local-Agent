go test -tags headless ./internal/native/engine/ -count=1 -run TestRealCppHostPhase5 -v
# → TestRealCppHostPhase5EndToEndGeneration PASS   (CI failure #1)
# → TestRealCppHostPhase5ContextOverflow PASS      (CI failure #2)

Environment-limited step, honestly recorded: non-headless
`go test ./...` requires gtk4/webkitgtk system libraries that this sandbox
does not have; the failure was verified PRE-EXISTING at the base commit
(same pkg-config errors on the untouched tree). CI runners install the
libraries (the workflow does so explicitly).

The CI failure was fixed by ROOT CAUSE, proven: reverting only the
`host_main.cpp` fix reproduces the exact CI signature ("hello" →
promptTokens: 7, merges dropped) deterministically in the new regression
test; restoring the fix makes it green. The numbers were never touched.
